Crypter-Tools - Personal tools for security on PC!

# Tools 

 * Crypter - console tool for crypting data
 * crypted-note - personal secure notepad
 * piped - tools for crypt net-connections


# Prepare code

```
git submodule update --init --remote --recursive
git pull --recurse-submodules 
```

# Dependencies

```
sudo cpan install Rand::Urandom
```

# Installation

```
sudo ./Install.sh
```

# Usage

Looking for:

```
man crypter
man crypted-note
man piped
```
